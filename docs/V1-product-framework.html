AI 职场 X 光

V1 产品框架 · 2026-08-07

1 V1 产品定位

帮你用可观察事实判断职场处境，而不是凭感觉猜。

一个轻量职场信号预警工具——用户描述最近职场变化，AI 通过结构化问诊区分事实、推测与情绪， 输出一份基于可观察信号的局势评估报告，附带短期行动计划。

2 V1 用户核心路径

🏠 首页输入 → 🔍 快速/深度问诊 → 📊 报告生成 → 📤 分享 / PDF 保存 → 🔄 复测
首页输入50 字起输入，描述变化 → 选快速(5轮)/深度(10轮)模式
结构化问诊动态追问（澄清 → 时间线 → 反向验证），区分事实与推测
报告生成本地启发式引擎 + Cloudflare Workers AI 双引擎，12 个固定模块
分享/保存复制纯文本摘要 + 导出 PDF + 生成匿名分享链接
复测首页 → 开始新检测，历史记录可查看过往报告

3 V1 功能边界

✅ 做

  • 基于用户描述，结构化追问还原完整上下文
  • 从五维（权力/资源/信息/关系/替代）信号扫描
  • 输出综合风险评分（0-100）和等级
  • 区分事实/推测/情绪，标注每句话的证据层级
  • 标注"目前不能确认"的部分，主动提示信息缺口
  • 生成分时段行动计划（72h/7d/30d）
  • 提供未来 30 天观察清单
  • 支持快速（5轮）和深度（10轮）两种问诊

❌ 不做

  • 法律建议——不判断是否构成劳动纠纷
  • 心理诊断——不评估抑郁/焦虑等心理状态
  • 替用户做职业决定——不说"你应该离职"
  • 替用户判断他人真实意图——只能基于可观察行为分析模式，不做读心术
  • 替代专业咨询——所有建议均为"信号参考"而非确定性结论

4 V1 报告固定模块（12 个）

① 一句话结论
多维信号+证据量决定，6级文案
② 风险等级与评分
0-100 分 + 5 级风险 + 颜色条
③ 五维扫描
雷达图 + 5个维度卡片（评分/解释/信号）
④ 已确认事实
用户明确描述的可观察行为
⑤ AI 判断
基于事实的逻辑推断 + 待验证假设
⑥ 不能确认的部分
信息缺口 + 需要继续观察的信号
⑦ 偶然 vs 趋势
频率/持续性/是否涉及核心资源
⑧ 3 种可能性
从解释维度拆解 3 种可能情景
⑨ 未来 30 天观察点
按维度分数动态挑选 3 个关键信号
⑩ 建议做/不做的事
各 3 条行动指引
⑪ 分时段行动计划
72h / 7d / 30d 三阶段
⑫ 免责声明
工具边界提示

注：⑧-⑨ 视 AI 返回数据可有可无（未来趋势判断为可选区块），其余均为必出模块。
